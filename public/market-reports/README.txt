GWI Market Report decks — 30 markets

Each market has two files:
  "<Market> Market Report.dc.html"        interactive deck (nav, thumbnail rail, links)
  "<Market> Market Report-print.dc.html"  flattened copy used for PDF export

Runtime files required alongside them:
  support.js, deck-stage.js, _ds/.../colors_and_type.css
  assets/  (slide 03 platform image)
  uploads/GWI Lockup Logo.svg  (cover + end card)

Fonts (Instrument Sans) load from Google Fonts; the design-system CSS pulls
Faktum webfonts from GitHub. Both need network access, or swap for local copies.

Built from GWI Core Q2-Q3 2025 market report PDFs, February 2026.
